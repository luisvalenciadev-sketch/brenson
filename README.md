# Brenson Ecosistema

Monorepo del ecosistema digital de Brenson S.A.S. (Shopify, B2C + B2B).

| Carpeta | Contenido |
|---|---|
| `brenson-theme/` | Tema Shopify basado en Dawn v16.0.0 con módulos `brenson-*` |
| `brenson-services/` | Backend serverless (Cloudflare Workers): leads, cotizaciones PDF, webhooks, upload |
| `brenson-b2b-functions/` | App custom con Shopify Function de descuento por tier |
| `mock-data/` | Datos simulados que reemplazan lo que Brenson aún no entrega |
| `stitch-design/` | Exportaciones de las pantallas diseñadas en Stitch |
| `docs/` | Plan, decisiones, estrategia de simulación, metafields, manuales |

Ver `docs/ESTRATEGIA_SIMULACION.md` para saber qué es simulado y cómo se reemplaza.
